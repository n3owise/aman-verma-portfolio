# AMAN VERMA — A Visual World

Interactive portfolio for **Aman Verma** — graphic designer, AI visual creator & video editor.

> Concept: *a mind in motion.* The site is an editorial print studio on warm paper:
> ideas exist as physical artifacts (plates, prints, frames), interrupted by dark
> "screen" chapters for AI and motion work.

Reference experience: trevornoah.com (interaction principles only — see
`REFERENCE_ANALYSIS.md`). Design tokens & rules: `DESIGN_SYSTEM.md`.

---

## Stack

| Layer | Choice | Why |
|---|---|---|
| Framework | Next.js 15 + React 19 + TypeScript | App Router, SSG, metadata API |
| Motion | GSAP 3.13 (+ ScrollTrigger, SplitText) | Scroll choreography, line-mask reveals |
| Smooth scroll | Lenis | Weighted scroll physics wired to GSAP ticker |
| WebGL | Three.js (raw, one lazy shader plane) | Hero "ink field" — strategic, not decorative |
| Styling | Hand-written CSS design system (`app/globals.css`) | Full art direction control, zero framework weight |

No other runtime dependencies. Everything else is deliberate restraint.

## Run it

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # production build (fully static)
npm run start      # serve the production build
npm run typecheck  # strict TS check
```

Set a canonical URL before deploying:

```bash
NEXT_PUBLIC_SITE_URL=https://your-domain.com npm run build
```

Deploy anywhere Next.js runs (Vercel: import repo → deploy; self-hosted:
`npm run build && npm run start`). All routes are prerendered static.

## Pages

| Route | What |
|---|---|
| `/` | Loader → hero (interactive type + ink field) → manifesto → selected work → creative desk → about teaser → AI slider → tools wall → motion reel → playground teaser → contact finale |
| `/work` | Editorial index with cursor-trailing previews |
| `/work/[slug]` | Case study chapters (intro → context → concept → gallery → next) |
| `/about`, `/contact`, `/playground` | Statement pages / closing CTA / experiments |

Easter egg: press **⌘G** (or Ctrl+G) to overlay the layout grid.

## Editing content (no component surgery needed)

- `data/site.ts` — name, roles, email, socials, location. Replace placeholder
  social `href: "#"` links with real profiles.
- `data/projects.ts` — every project: title, category, year, role, tools,
  summary, context/concept copy, gallery specs, pull quote. Add/remove projects
  freely; routes and the sitemap update automatically.
- `data/tools.ts`, `data/experiments.ts` — tools wall + playground cards.
- Copy lives in section components under `components/sections/`.

### Replacing placeholder artwork

All imagery is generated by `components/Plate.tsx` — deterministic SVG
"placeholder plates" (halftone, specimen, scan, mesh, letter, grid, stripes)
so no fake client work is ever claimed. To use real work:

1. Drop exports into `public/work/<slug>/`.
2. In `data/projects.ts`, give each project an optional `image` field per
   gallery item and render `<Image>` in `Plate`'s place (the `media` wrapper
   already handles object-fit).
3. Delete `Plate` imports when fully migrated.

The video lightbox in the motion reel is wired for a muted MP4 + poster — drop
files in `/public` and pass them via a project's `video` field.

## Architecture

```
app/            routes, layout (fonts/metadata/JSON-LD), template (enter fade)
components/
  sections/     home chapters (Hero … ContactFinale)
  Providers.tsx Lenis + GSAP ticker + route-change reset
  PageTransition.tsx  wipe transition provider + <TLink>
  Navigation.tsx fixed nav + fullscreen clip-circle menu
  CustomCursor.tsx    data-cursor label system
  Plate.tsx     generative placeholder artwork
  PortraitFragments.tsx / AIDiffSlider.tsx / CaseGallery.tsx / WorkIndex.tsx
data/           structured content (CMS-ready shape)
lib/            gsap registration, animation utils (textReveal, imageReveal,
                parallax, magnetic, marquee), hooks, loader pub-sub, lenis store
```

Animation utilities are shared (`lib/animations.ts`) — components never
hand-roll ScrollTrigger setups. Every client effect runs inside
`gsap.context()` and reverts on unmount (no orphaned triggers).

## Accessibility & performance

- Semantic landmarks, skip link, visible focus, Esc closes menu/lightbox,
  background `inert` while the menu is open.
- `prefers-reduced-motion`: loader collapses instantly, Lenis off, parallax /
  letter physics / cursor off, marquees static. Content never depends on motion.
- No-JS: all content renders server-side; loader/wipe/cursor hide via noscript.
- WebGL lazy-inits only on pointer-fine desktops, pauses offscreen/hidden tab,
  DPR ≤ 1.5, falls back silently to the CSS fragment collage.
- Static generation everywhere; Three.js is a lazy chunk (~170kB first load on
  home incl. GSAP+Lenis; three loads on demand).

## SEO

Metadata templates per route, Open Graph image (`app/opengraph-image.tsx`),
`sitemap.xml`, `robots.txt`, JSON-LD `Person` schema. Analytics intentionally
omitted — add privacy-conscious tooling if ever needed.
