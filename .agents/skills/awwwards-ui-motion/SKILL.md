# Awwwards UI/UX & Motion Engineering Skill

This skill guides the design and development of award-winning digital experiences:

## Core Principles:
- **Liquid Continuity**: Transitions between sections and preloader screens should never hard-cut. Use curved SVG path morphing (`Q x y`), clip-path wipes, or coordinated staggered reveals.
- **Physical Inertia**: Elements reacting to scroll must feel grounded with weight and momentum (`gsap.quickTo`, `gsap.ticker` spring lerping, velocity skewing).
- **Sub-Pixel Precision**: Avoid layout reflows during continuous animations. Animate only composited transforms.
- **Micro-Delight**: Responsive magnetic attraction on CTAs, progressive typographic weight variations, and ambient floating meshes.
